# MusicPlayer: iOS Audio Application

## Краткое описание проекта

Данный проект представляет собой реализацию музыкального плеера для **iOS**, разработанного в соответствии с требованиями задания.  
Приложение построено на фреймворке **UIKit** (не SwiftUI) с использованием языка **Swift (iOS 15+)**.  

Основной акцент сделан на использовании **UIStackView** для создания гибкого, адаптивного и правильно центрированного интерфейса.  
Воспроизведение аудиофайлов реализовано с помощью фреймворка **AVFoundation (AVAudioPlayer)**.

---

## Технические особенности реализации

- **Фреймворк:** UIKit  
- **Основной Layout:** UIStackView и Auto Layout (без конфликтов ограничений)  
- **Управление:** Реализована циклическая навигация между 11 треками (Next / Previous)  
- **Иконки:** Использованы стандартные SF Symbols для кнопок управления  
- **Обработка ошибок:** Добавлена проверка наличия аудиофайлов при загрузке трека  

---

## Выполненные бонусные задачи

| Бонус | Описание |
|-------|-----------|
| **Bonus 1 (Progress Bar)** | Добавлен `UIProgressView`, который визуально отображает прогресс воспроизведения в реальном времени |
| **Bonus 2 (Duration Display)** | Реализовано отображение текущего времени и общей длительности трека в формате `М:СС` |
| **Bonus 3 (Artist Name Display)** | Добавлена отдельная метка для отображения имени исполнителя под названием трека |
| **Bonus 4 (Shuffle & Repeat)** | Добавлены кнопки для управления режимами: Shuffle (случайный порядок) и Repeat (циклическое переключение режимов: Выкл, Повтор всего, Повтор одного) |
| **Bonus 5 (Dark Mode Support)** | Приложение использует семантические цвета (`.label`, `.systemBackground`), обеспечивая корректное отображение в системных Светлом и Тёмном режимах |

---

## Дополнительный функционал

- Добавлена кнопка-переключатель для смены фонового изображения (**dark/light**)  
- Пользователь может вручную изменять визуальную тему приложения

## 🖼️ Используемые ресурсы

| Тип ресурса | Использование | Источник |
|--------------|---------------|----------|
| **Иконки** | Кнопки управления (`play.fill`, `shuffle`, `repeat` и т.д.) | Apple SF Symbols |
| **Аудио** | 11 файлов в формате `.mp3` (для плейлиста) | Кастомные файлы |
| **Изображения** | 11 обложек альбомов, 2 фоновых изображения и их иконка (light, dark) | Кастомные / сторонние |
